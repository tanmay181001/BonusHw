## 📂 Project Description
This project analyzes employee data from a CSV file using core Java and Object-Oriented Programming principles. It performs data-driven tasks such as:

1. Finding the lowest-paid employee in each department  
2. Listing employees with less than 4 years of service  
3. Calculating the average salary in the Marketing department  
4. Identifying the longest-tenured employee(s)  
5. Counting the number of team leads per department  

The program is modular, efficient, and utilizes Java collections, file handling, and lambda expressions for data manipulation.

## 🧱 Project Structure

- EmployeeAnalyzer.java – Main driver with Employee and Company classes
- employee_data.csv – Sample dataset used for processing
- Project_Report.docx – Report explaining class structure, output samples, and OOP design
